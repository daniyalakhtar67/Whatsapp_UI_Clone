WhatsApp UI Clone

A front-end clone of WhatsApp, built to practice recreating a real-world, widely-used app interface pixel by pixel. It walks through the same screens you'd hit on a fresh install — number verification, the welcome/consent screen, chats, and status — all styled to match WhatsApp's signature look.

Features
Phone number verification screen with country picker and dial code
Welcome screen with privacy policy / terms of service consent
Chats tab — chat list with avatars, last message preview, timestamps, and unread message badges
Status tab — "My Status" plus a feed of recently updated contacts
Bottom navigation between Chats, Status, and Calls
WhatsApp's signature green theme and clean, familiar layout

Why this project?
WhatsApp is one of the most recognizable UIs out there, which makes it a great target for practicing layout, navigation, and attention to detail. This project isn't about building a real messaging app — there's no backend and no messages actually being sent — it's purely a UI/UX exercise in recreating something people already know well.
